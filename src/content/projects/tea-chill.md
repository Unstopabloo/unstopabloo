## Contexto

Tea Chill es un proyecto de e-commerce donde prioricé la performance del sitio. Next.js como frontend y Shopify como headless CMS permiten una experiencia de compra fluida sin sacrificar la flexibilidad del contenido.

## Stack

- Next.js (App Router)
- Shopify Storefront API
- Optimización de imágenes y Core Web Vitals
